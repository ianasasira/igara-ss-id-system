Igara ID Studio

Student ID card automation

Intake – raw photos & signature sheets → passports + signatures

Pick a class, drop in the raw pictures, and the app crops passport-style (head, shoulders, upper chest), cuts out each signature, and names both by reading the name written on the paper. Check the list, fix anything, then save into the project. Everything runs on this computer – no photos are uploaded anywhere.

1 · Student photos

Any size/orientation, with the student holding their name on paper.

or drag & drop
2 · Signature sheets

Photos/scans of the paper with the signature and the name written on it.

or drag & drop

Review

Class list

Paste the official student names, one per line. Names read from the paper are matched to this list, which fixes most handwriting mistakes (like a letter hidden behind a finger).

Edit all names

One name per line, in the same order as the list. Change the text on any line, but don’t add or delete lines.

Project folder

The folder that contains S.1 … S.6, SIGNS and new/empty template.png (your “gara id” folder).

ID template

The blank card design (1011 × 638 PNG). Stored as new/empty template.png in the project folder.
